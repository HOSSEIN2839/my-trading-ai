# My Trading AI

ربات پژوهشی ترید رمزارز با تحلیل تکنیکال + تأیید هوش مصنوعی (Gemini)، مدیریت ریسک و شبیه‌سازی معاملات.

> **حالت پیش‌فرض فقط Paper Trading است.** این پروژه در نسخه فعلی سفارش واقعی ارسال نمی‌کند. سودآوری تضمین نیست؛ قبل از هر استفاده واقعی، بک‌تست و Paper Trading طولانی لازم است.

## قابلیت‌ها
- دریافت کندل‌های بازار از صرافی با CCXT (در نسخه فعلی داده عمومی Binance؛ بدون کلید API)
- شاخص‌های EMA 50/200، RSI و ATR
- دریافت نظر ساختاریافته از Gemini؛ اگر کلید AI تنظیم نباشد یا پاسخ نامعتبر باشد، معامله‌ای انجام نمی‌شود
- شبیه‌سازی خرید/فروش اسپات، حد ضرر و حد سود، سقف ریسک و گزارش CSV
- ذخیره وضعیت شبیه‌ساز و ثبت خطاها
- تست‌های پایه برای محاسبات و مدیریت ریسک

## شروع سریع (Windows / PowerShell)
1. Python 3.11 یا جدیدتر نصب باشد.
2. در پوشه پروژه اجرا کن:
   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   Copy-Item .env.example .env
   ```
3. فایل `.env` را باز کن و `GEMINI_API_KEY` را وارد کن.
4. اجرا:
   ```powershell
   python -m src.bot
   ```
5. توقف با Ctrl+C.

## تنظیمات مهم
- `MODE=paper`: تنها حالت پشتیبانی‌شده در این نسخه.
- `SYMBOL=BTC/USDT` و `TIMEFRAME=15m`: بازار و بازه کندل.
- `INITIAL_BALANCE=1000`: موجودی مجازی به واحد USDT.
- `RISK_PER_TRADE=0.005`: ریسک مجازی ۰٫۵٪ در هر معامله.
- `MAX_DAILY_LOSS=0.02`: توقف معاملات مجازی پس از افت روزانه ۲٪.
- `GEMINI_MODEL=gemini-2.5-flash`: مدل AI.

## معماری
- `src/market.py`: داده بازار و شاخص‌ها
- `src/ai_analyst.py`: تحلیل Gemini با خروجی JSON محدود
- `src/risk.py`: محاسبه حجم و کنترل ریسک
- `src/paper_broker.py`: شبیه‌ساز معاملات
- `src/bot.py`: حلقه اصلی

## محدودیت‌های نسخه
این نسخه **به حساب صرافی وصل نمی‌شود و پول واقعی معامله نمی‌کند**. حد ضرر/حد سود در شبیه‌سازی بر اساس قیمت کندل بررسی می‌شود و پرشدن سفارش، کارمزد، لغزش قیمت و شکاف بازار در دنیای واقعی را دقیق بازسازی نمی‌کند. ابتدا باید بک‌تست با داده تاریخی، آزمون‌های بیشتر و اجرای آزمایشی انجام شود. کلیدهای صرافی را در GitHub قرار نده؛ اگر در آینده اتصال واقعی اضافه شد، برداشت وجه را در مجوز API غیرفعال کن.
