# My Trading AI

ربات پژوهشی ترید رمزارز با سه لایهٔ تصمیم‌گیری: شاخص‌های تکنیکال، تحلیل Gemini و مدل یادگیری ماشین آموزش‌دیده روی کندل‌های تاریخی.

> **حالت فقط شبیه‌سازی (Paper Trading) است.** سفارش واقعی ارسال نمی‌شود و سودآوری تضمین نیست.

## یادگیری ماشین چه می‌کند؟
- دادهٔ تاریخی را به ویژگی‌هایی مثل بازده قیمت، فاصلهٔ EMAها، RSI، ATR و تغییر حجم تبدیل می‌کند.
- بر اساس بازده سه کندل آینده در دادهٔ آموزشی، برچسب BUY / SELL / HOLD می‌سازد.
- یک مدل Random Forest آموزش می‌دهد و آن را روی بخش زمانیِ جدیدترِ داده‌ها ارزیابی می‌کند.
- خروجی مدل همراه با تحلیل تکنیکال و Gemini بررسی می‌شود؛ برای ورود، هر سه باید با هم موافق باشند.
- اگر مدل آموزش‌دیده وجود نداشته باشد، ربات شروع نمی‌شود.

**محدودیت مهم:** این هنوز یادگیری خودکار پس از هر معامله نیست. آموزش مجدد فعلاً دستی است. دقت طبقه‌بندی هم برابر با سوددهی نیست؛ مرحلهٔ بعدی باید بک‌تست واقع‌بینانه با کارمزد، لغزش قیمت و ارزیابی روی بازه‌های زمانی کاملاً دیده‌نشده باشد.

## نصب در Windows / PowerShell
در پوشهٔ پروژه اجرا کن:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

کلید Gemini را فقط در فایل محلی `.env` وارد کن. آن را در GitHub منتشر نکن.

## ترتیب اجرا
ابتدا مدل یادگیری ماشین را با دادهٔ عمومی آموزش بده:

```powershell
python -m src.train_model
```

این دستور مدل محلی را در `data/model.joblib` و گزارش ارزیابی را در `data/training_report.json` ذخیره می‌کند. سپس تست‌ها را اجرا کن:

```powershell
python -m pytest -q
```

در نهایت ربات آزمایشی را اجرا کن:

```powershell
python -m src.bot
```

توقف با `Ctrl+C`.

## تنظیمات
- `MODE=paper`: تنها حالت پشتیبانی‌شده.
- `SYMBOL=BTC/USDT` و `TIMEFRAME=15m`: بازار و بازهٔ زمانی.
- `INITIAL_BALANCE=1000`: موجودی مجازی به USDT.
- `RISK_PER_TRADE=0.005`: ریسک هدف هر معاملهٔ مجازی ۰٫۵٪.
- `MAX_DAILY_LOSS=0.02`: توقف ورودهای جدید پس از زیان روزانهٔ ۲٪.
- `GEMINI_API_KEY`: کلید محلی برای تحلیل Gemini؛ بدون کلید، تحلیل AI به HOLD تبدیل می‌شود.

## ساختار
- `src/market.py`: داده و شاخص‌های تکنیکال
- `src/learning.py`: ویژگی‌ها و پیش‌بینی مدل آموزش‌دیده
- `src/train_model.py`: آموزش و ارزیابی زمانی
- `src/ai_analyst.py`: تحلیل Gemini و ترکیب سیگنال‌ها
- `src/risk.py`: اندازهٔ موقعیت و کنترل زیان
- `src/paper_broker.py`: شبیه‌ساز معاملات و گزارش CSV
- `src/bot.py`: حلقهٔ اصلی

## ایمنی
این نسخه به حساب صرافی وصل نمی‌شود و پول واقعی معامله نمی‌کند. شبیه‌سازی، پرشدن سفارش، کارمزد، لغزش قیمت و شکاف بازار را به‌طور کامل بازسازی نمی‌کند. قبل از هر تصمیم برای اتصال واقعی، لازم است بک‌تست هزینه‌محور، آزمایش خارج از نمونه و اجرای آزمایشی طولانی انجام شود. کلیدهای API صرافی را در GitHub قرار نده؛ در آینده نیز مجوز برداشت باید غیرفعال باشد.
